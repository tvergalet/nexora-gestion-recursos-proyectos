# Sistema Integrado Inteligente de Gestión de Recursos y Proyectos

## Descripción

Este repositorio contiene la documentación del proyecto académico desarrollado para Nexora Consulting Argentina.

El proyecto propone el diseño de un Sistema Integrado Inteligente de Gestión de Recursos y Proyectos orientado a mejorar el proceso de identificación y selección de profesionales para proyectos de consultoría.

La solución integra información corporativa proveniente de Workday y utiliza inteligencia artificial como herramienta de apoyo para analizar perfiles y recomendar profesionales según criterios como competencias, experiencia, disponibilidad y asignaciones actuales.

Las recomendaciones generadas funcionan como soporte para la toma de decisiones. La selección final de un profesional permanece bajo responsabilidad de los responsables del proyecto.

## Objetivos principales

- Reducir el tiempo necesario para identificar profesionales adecuados para un proyecto.
- Centralizar información relevante para la búsqueda y evaluación de perfiles.
- Generar recomendaciones de candidatos mediante inteligencia artificial.
- Informar la disponibilidad y asignaciones actuales de los profesionales.
- Detectar y advertir sobre perfiles cuya información pueda encontrarse desactualizada.
- Mantener la decisión final de asignación bajo criterio humano.
- Integrarse con Workday como fuente corporativa de información.
