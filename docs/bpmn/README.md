# Modelado BPMN

Esta carpeta contiene el modelado BPMN del proceso de identificación y selección de profesionales para proyectos de Nexora Consulting Argentina.

El proceso representa la interacción entre el Project Manager, el Sistema Integrado Inteligente de Gestión de Recursos y Proyectos, Recursos Humanos y los sistemas corporativos utilizados para consultar y registrar información.

El modelo contempla tanto el flujo habitual de búsqueda y selección como situaciones alternativas, entre ellas:

- Refinamiento de los criterios de búsqueda.
- Perfiles con información desactualizada.
- Selección manual de profesionales.
- Profesionales con disponibilidad parcial.
- Coordinación entre responsables de distintos proyectos.
- Ausencia de candidatos internos adecuados.
- Evaluación de alternativas externas por parte de Recursos Humanos.
- Integración con Workday para la consulta de información y el registro oficial de asignaciones.

La herramienta propuesta funciona como soporte para la toma de decisiones. La selección final de los profesionales continúa siendo responsabilidad de los responsables del proyecto.
